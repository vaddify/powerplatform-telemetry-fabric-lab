# Vertical lenses

Each file here is a **delta** on the base [business-use-case.md](../business-use-case.md). It does not replace the base; it adds:

1. Regulatory drivers and citations.
2. Tier-3 KPIs unique to the vertical.
3. Data tags / classifications to apply in the silver/gold layers.
4. Alert thresholds tuned for the vertical's risk appetite.
5. Suggested DAX measures.
6. Lab variation (if any) on top of the base low-code / pro-code labs.

| File | Vertical |
|---|---|
| [financial-services.md](./financial-services.md) | Banking, capital markets, insurance |
| [healthcare.md](./healthcare.md) | Providers, payers, life sciences |
| [retail.md](./retail.md) | Retail, CPG, e-commerce |
| [manufacturing.md](./manufacturing.md) | Discrete + process manufacturing, supply chain |
| [public-sector.md](./public-sector.md) | Federal, state/local, education, defense |
| [energy.md](./energy.md) | Oil & gas, utilities, renewables |

To add a new vertical, copy `_template.md` and fill in the seven sections.
